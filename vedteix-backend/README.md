# Vedteix Backend

## Setup

```bash
cd vedteix-backend
npm install
cp .env.example .env
# Edit .env as needed
npm run dev
```

- Runs at http://localhost:5000
- Make sure MongoDB is running and .env is configured.

## Build for Production

```bash
npm start
```
